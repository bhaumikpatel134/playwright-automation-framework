# Playwright Automation Framework

UI automation framework built using Playwright and JavaScript.

## Overview

This repository demonstrates UI automation testing concepts using Playwright and JavaScript. The project covers login validation, product validation, cart functionality, checkout workflows, and end-to-end testing scenarios.

## Features

- Login Automation
- Product Validation
- Cart Validation
- Checkout Validation
- Playwright Assertions
